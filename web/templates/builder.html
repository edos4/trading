Saved

Pick a saved indicator to edit, or start a new one. Saved indicators live in PostgreSQL (rules.indicator_rules); deleting one is refused while a paper book is running it.

Name is the label shown everywhere. Timeframe selects the bars the rule reads. Direction is the action taken when the whole tree matches.

Each condition compares an indicator value (left) with a number or another indicator (right). Bars ago shifts either side back by N bars, which is how you compare against a previous value. A block is a group of conditions with one AND/OR connector; drag the ⠿ handle to reorder, or use ▲/▼.

Exit

Exit when the rule stops matching closes on the first bar the tree becomes false. Stop protects the entry (percent, ATR, or a default 2×ATR) and Target is optional. Max hold forces a time exit even while the rule still matches.

Attach to Patternsv2

Choose Off, Before or After, then pick one Patternsv2 pattern (or All).

Filter rejects signals while this rule is false. Shadow never blocks; it records the rule evidence on each signal.

Placement decides when the rule is checked relative to the detector; Pattern scopes it to one specific Patternsv2 shape (or all); Mode controls whether matching signals are vetoed or merely recorded. The Paper tab reuses this saved attachment when the rule is selected as a filter.

Preview

Preview evaluates the current draft over the last N bars and lists each condition's value, pass/fail and the final match, so you can verify the rule without saving or placing a trade.

Backtest

Backtest uses the saved rule (save first). Entries fill at the next bar's open; exits are rule-false, stop, target, max-hold or end of data. The table is the raw trade list; the second table is the rule's match timeline for reconciling the result.

Start paper book

With Attach to Patternsv2 = Off, the saved rule becomes the book's own strategy (one open position per symbol). With an attachment, this starts a Patternsv2 book with the rule applied at the saved pattern/placement/mode. To gate an existing book manually, pick the rule on the Paper tab as a rule filter.
