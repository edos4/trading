# Indicators that could not be coded

These Facebook reels name a TradingView script and show a chart, but not the calculation. The scripts are closed-source (AlgoAlpha, Flux Charts, or an unnamed community script), so a faithful detector cannot be built from the reel.

- **Smart Signals [AlgoAlpha]** — "The Perfect Pullback Setup". The reel searches "Smart Sign" and shows a ribbon with bullish triangles. The formula is not on screen. Smart Signals Assistant is the same closed script.
  
- **Momentum Concepts [AlgoAlpha]** — "This Free Indicator Finds Reversals Before The Move". The script is locked. The reel shows a regression channel and a "momentum = extreme" caption, not the thresholds.

- **Trinity Reversal Pattern [AlgoAlpha]** — "This FREE Indicator Finds Reversals in Just 3 Candles". The name is the only rule given. Which three candles, and against which filter, is not shown.

- **ORB Algo | Flux Charts** — "This FREE Opening Range Breakout is OVERPOWERED". Opening-range breakout itself is a known idea, but this script adds undisclosed filters, and the explorer only has daily and weekly bars. Those bars do not contain the session opening range the script trades.

- **Pro Scalper** — "Try this Pro Scalper tool in your next session". A community script on a 45-second XRP chart. No author, inputs, or rules are shown.

- **Trend Targets [AlgoAlpha]** — "Top Trends Target Indicator on TradingView". The reel only shows the script in the indicator search. No settings or target formula.
