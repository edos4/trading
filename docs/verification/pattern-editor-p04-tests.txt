## Regression fixes found during the gate

- `test_pattern_bootstrap.py::test_load_without_detector_files_and_isolated_helpers`
  failed with a trusted-runtime mismatch: `runtime_manifest` walked the `patterns/`
  package initializer and its detector imports, so deleting detector files removed a
  reachable dependency (`data/edgar_client.py`) from the fingerprint. `collect_sources`
  now accepts `prune_package` and `runtime_manifest` prunes `patterns/`, keeping the
  trusted runtime fingerprint independent of detector/helper sources (P04-07).
- `analysis/test_pattern_overlays.py::test_detected_pennant_saves_both_converging_rails`
  failed only when a prior in-process `_core_backtest_symbol` run had left the global
  `patterns._dedup` walk state set (`_current`). `_core_backtest_symbol` now resets the
  registry before returning, matching the documented "empty outside a backtest" boundary
  (P04-06 isolation).
